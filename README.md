# حوّل (Hawwil)

تطبيق عجلة الملفات: اسحب ملفاً وأفلته على الخيار لتحويله أو تعديله أو تثبيته. عربي/إنجليزي، فاتح/داكن. الملفات تبقى محفوظة داخل التطبيق.

- `web/` الواجهة (مصدر واحد لكل النسخ). تُنشر على GitHub Pages ويمكن تثبيتها على الجوال من المتصفح.
- `windows/` نسخة ويندوز (Electron). تُبنى تلقائياً وتظهر في Releases.
- `android-app/` نسخة أندرويد (Capacitor). تُبنى تلقائياً ويظهر ملف `Hawwil.apk` في Releases.

## التنزيل
من صفحة **Releases** حمّل: `Hawwil Setup x.x.x.exe` (ويندوز، مثبّت) أو `Hawwil x.x.x.exe` (محمول) أو `Hawwil.apk` (أندرويد).
على أندرويد: افتح الملف وافسح «التثبيت من هذا المصدر» إذا طلب.

## التحديث
زر «التحقق من التحديث» في الإعدادات يفحص آخر إصدار على GitHub ويحدّث التطبيق.

## نشر إصدار جديد
1. عدّل `web/index.html` (غيّر `const VERSION='...'`) و`web/version.json` إلى الرقم الجديد.
2. ارفع التغييرات على main. تُبنى النسخ تلقائياً وتُنشر في Releases بوسم `vX.Y.Z`.

## أول مرة
Settings ← Pages ← Source: GitHub Actions.
